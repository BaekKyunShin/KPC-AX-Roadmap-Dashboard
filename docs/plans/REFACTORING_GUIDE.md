
### 2단계: 아래 프롬프트 붙여넣기

```
docs/plans/2026-02-12-system-refactoring-plan.md 계획서를 읽고,
진행 추적표에서 다음 미완료 항목 1개만 진행해. /using-superpowers

규칙:
- 이번 세션에서는 해당 Session 1개만 수행하고 멈출 것
- 기능 변화 절대 없음
- 세션 체크리스트 템플릿 따를 것
- 완료 후 진행 추적표를 업데이트할 것
- 다음 항목으로 넘어가지 말 것
```

**이게 전부입니다.** 이후는 Claude가:

1. 계획서를 읽고 다음 미완료 세션 **1개**를 찾음
2. CLAUDE.md 스킬 규칙에 따라 필요한 스킬 호출
3. 대상 파일 분석 → 테스트 작성 또는 리팩터링 수행
4. `npm run validate` 실행하여 검증
5. 커밋
6. 계획서 추적표에 `완료` 표시
7. **멈춤** (다음 항목으로 넘어가지 않음)

| Phase | Session 수 | 하루 2세션 기준 |

선택적 세션을 모두 건너뛰면 25세션, 모두 포함하면 35세션.

## FAQ

**Q: 매번 새 세션을 열어야 해?**
A: 권장. 컨텍스트가 깨끗해서 정확도가 높음. 같은 세션에서 이어하려면 "다음 미완료 항목 1개만 이어서 진행해"로 요청.

**Q: 하루에 몇 세션이 적당해?**
A: 1~3세션. 각 세션 후 결과를 확인하고 넘어가는 게 안전함.

**Q: 중간에 일반 기능 개발을 해도 돼?**
A: 됨. 리팩터링 계획서는 독립적. 기능 개발 후 다시 리팩터링 프롬프트를 쓰면 추적표에서 다음 미완료 항목부터 이어감.

**Q: 계획서 내용이 실제 코드와 안 맞으면?**
A: "계획서의 Session X-Y를 수정해줘"로 요청. 작업 중 차이를 발견하면 Claude가 알려줌.

**Q: Claude가 "다음도 할까요?"라고 물으면?**
A: 원하면 "진행해", 아니면 "여기서 멈춰"라고 답하면 됨.
