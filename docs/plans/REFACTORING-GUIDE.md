**이게 전부입니다.** 이후는 Claude가 알아서:

1. 계획서를 읽고 다음 미완료 세션을 찾음
2. CLAUDE.md 스킬 규칙에 따라 필요한 스킬 호출
3. 대상 파일 분석 → 테스트 작성 또는 리팩터링 수행
4. `npm run validate` 실행하여 검증
5. 커밋
6. 계획서 추적표에 `완료` 표시

## FAQ

**Q: 매번 새 세션을 열어야 해?**
A: 권장. 컨텍스트가 깨끗해서 정확도가 높음. 단, 한 세션에서 작업이 일찍 끝나면 "다음 항목도 이어서 진행해"로 이어갈 수 있음.

**Q: 하루에 몇 세션이 적당해?**
A: 1~3세션. 각 세션 후 결과를 확인하고 넘어가는 게 안전함.

**Q: 중간에 일반 기능 개발을 해도 돼?**
A: 됨. 리팩터링 계획서는 독립적. 기능 개발 후 다시 리팩터링 프롬프트를 쓰면 자동으로 다음 미완료 항목부터 이어감.

**Q: 계획서 내용이 실제와 안 맞으면?**
A: "계획서의 Session X-Y를 수정해줘"로 요청. 작업 중 Claude가 계획과 실제 코드의 차이를 발견하면 알려줌.

**Q: 선택적(선택) 세션은 건너뛰어도 돼?**
A: 됨. 건너뛰려면 "Session X-Y는 건너뛰고 추적표에 `건너뜀`으로 표시해줘"라고 요청.
