# 결과관리 기능 설계 (큰 그림)

> 작성일: 2026-04-11
> 상태: 초안 — 디테일은 구현 단계에서 확정

## 목적

로드맵 FINALIZED 이후의 **훈련 성과 기록·산출물 제출·과정 평가**를 관리하는 기능.
컨설턴트는 자기 담당 프로젝트의 완료 현황을 추적하고, 운영관리자는 전체 프로젝트 성과를 조감한다.

## 네비게이션 구조

### 컨설턴트

**홈** · **프로젝트** · **결과관리** · **프로필**

- `consultant/results` — 내 담당 프로젝트별 결과 제출 현황 대시보드
- 프로젝트 카드마다 완료율·미입력 항목 표시
- 클릭 시 프로젝트 상세 > 결과 탭으로 이동

### 운영관리자

기존 운영관리 메뉴에 **결과관리** 추가

- `ops/results` — 전체 프로젝트 성과 집계·비교·필터링
- 기업별/기간별/컨설턴트별 집계 뷰

### 프로젝트 상세 (공통)

기존 프로젝트 상세 화면에 **결과** 탭 추가 → 실제 데이터 입력/편집은 여기서

## 결과 탭 구성 (3개 서브탭)

### 1. 훈련 결과

| 섹션 | 내용 |
|------|------|
| 기업 경영 이슈 | 훈련 전 파악된 경영 이슈 |
| 개선 결과 | 훈련을 통해 개선된 사항 |
| 미해결된 이슈 | 남아있는 과제 |
| 정량·정성 지표 | 훈련 전/후 비교 수치 + 정성 평가 |
| 성과 확산 결과 | 조직 내 확산 현황 |
| 향후 계획 | 후속 조치 및 계획 |

- 리치 텍스트 + 수치 입력 혼합
- 지표는 **템플릿 기반 + 커스텀 추가** 방식 검토

### 2. 수행 결과물

- 산출물 유형 태그 (보고서, 매뉴얼, 데이터셋 등)
- 파일 첨부 (Supabase Storage 활용)
- 결과물별 설명·제출일

### 3. 과정 평가

- 평가 항목: 로드맵 모듈/커리큘럼에서 자동 추출 검토
- 항목별 수행 수준 1~5점
- 평가 기준 텍스트
- 레이더 차트 시각화

## 역할별 권한

| 동작 | 컨설턴트 | 운영관리자 |
|------|---------|-----------|
| 결과 입력/수정 | 자기 담당 프로젝트만 | 전체 |
| 결과 조회 | 자기 담당 프로젝트만 | 전체 |
| 집계 대시보드 | 내 프로젝트 현황 | 전체 프로젝트 집계 |
| 결과물 파일 업로드 | ✅ | ✅ |

## DB 테이블 (예상)

- `training_results` — 프로젝트별 훈련 결과 (6개 섹션 데이터)
- `training_deliverables` — 산출물 목록 + 파일 참조
- `course_evaluations` — 단원별 평가 점수 + 기준

> 스키마 상세는 구현 단계에서 확정. RLS 정책은 기존 프로젝트 접근 패턴(컨설턴트=담당 프로젝트만, 운영관리자=전체) 그대로 적용.

## 워크플로우 연동

- 프로젝트 상태에 새 단계 추가 여부는 미정
  - 옵션 A: `FINALIZED` 이후 `RESULTS_SUBMITTED` 상태 추가
  - 옵션 B: 상태와 무관하게 결과 입력 가능 (FINALIZED 이후부터)
- PDF 내보내기 시 성과 섹션 포함 여부 검토

## 구현 순서 (대략)

1. DB 스키마 설계 + 마이그레이션
2. 프로젝트 상세 > 결과 탭 (입력 UI)
3. `consultant/results` 목록 페이지
4. `ops/results` 집계 페이지
5. 파일 업로드 + Storage 연동
6. 차트·시각화
