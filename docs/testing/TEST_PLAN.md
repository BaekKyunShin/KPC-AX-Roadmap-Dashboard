## 테스트 방법론

- 에러 발생 시 중단하지 않고 기록 후 계속 진행
- JavaScript 콘솔 에러를 `puppeteer_evaluate`로 수집
- 파괴적 액션(사용자 승인/정지 등) 포함하여 실제 실행
