## Step 3. 기업 요구분석 (Ⅱ-2)

### 기업 현황 (status)

```
1986년 설립된 자동차 변속기·구동계 부품 전문 1차 협력사로 연 매출 약 760억(2025), 생산직 180명·사무기술직 68명을 고용한다. 주력 품목은 자동변속기용 정밀 기어(헬리컬·스퍼)·클러치 디스크·동력전달 샤프트로 약 220 품번을 생산하며, 핵심 공정은 단조 → CNC 정밀가공(56대) → 열처리(침탄·고주파) → 연삭(28대) → 외주 도금 → 출하검사로 구성된다. 매출의 약 60%는 현대트랜시스, 25%는 현대위아, 15%는 미국 Allison Transmission 향 수출로 이뤄지며, 사내 시스템은 SAP B1(ERP)·자체개발 MES·일부 IoT 센서(진동·온도, 12대)를 운영하나 데이터 분석·AI 도구는 도입 전 단계다. 최근 6개월간 CNC PLC 로그·MES 작업이력·검사 데이터가 자동 수집되어 누적 중이지만, 분석을 위한 인력·도구·표준이 부재하다.
```

### 주요 문제 (problem)

```
① 정밀 기어 치형 검사가 3D 측정기 + 검사자 판독 혼용으로 시간당 처리량이 부족하고, 검사자별 판정 차이로 Cpk 산출 신뢰도가 흔들려 고객사 PPAP 대응 시 재측정·재검사 비용이 분기당 약 4,200만 원 발생한다. ② 열처리(침탄) 공정 경도·침탄 깊이 산포로 후공정 연삭 시 가공 부하가 늘어 연삭휠 교체 주기가 단축(목표 800개 → 실적 620개)되고 가공불량 0.8%가 고착됐다. ③ 220 품번·일일 평균 14회 라인 셋업의 다품종 소량 환경에서 생산계획 담당자가 수기 엑셀로 일일 스케줄을 작성해 긴급 오더 대응에 평균 2.5시간 소요되고 CNC 가동률이 71% 정체 상태다. ④ 외주 도금업체(3개사) 품질 편차로 도금 박리·치수 불량 클레임이 월 평균 1.2건 발생하지만 업체별·로트별 데이터 분석 체계가 없어 근본원인 추적이 어렵다. ⑤ 생산직 평균 연령 47세·신규 채용 어려움으로 숙련공의 공정 노하우(예: 단조 가열온도 미세조정, 침탄 시간 보정)가 디지털화되지 않아 세대교체 시 손실 위험이 크다. ⑥ 전기차 감속기·드라이브유닛 신사업 R&D 진행 중이나 시뮬레이션·데이터 분석 도구 활용 경험이 없어 외부 컨설팅 의존도가 높다.
```

### 추진 의지 (will)

```
경영진은 2026년 사업계획에서 "AI 활용 역량 내재화"를 4대 전략과제 중 2번째로 명시하고, 이번 로드맵 완료 후 정밀 기어 치형 AI 검사 파일럿(예산 1.5억 원)과 열처리 산포 예측 분석(예산 6,000만 원)을 우선 추진하기로 내부 승인한 상태다. 김재영 경영지원본부장이 AI 추진위원장을 겸임하고, 품질보증·생산기술·R&D센터 책임자 4인을 핵심 멤버로 한 'AI Transformation TF'를 격주로 운영하며, 훈련 대상 인원은 사내 학습시간(주 4시간) 보장 및 사외 교육 참여 시 출장 처리한다. 이재용 대표는 분기별 임원회의에서 진척도를 직접 점검하며, 사외 컨설턴트와의 정기 미팅(월 1회)을 본인 일정에 고정 배정했다.
```

### 기대 성과 (outcomes)

```
① 정밀 기어 치형 AI 검사 도입으로 검사 처리량 1.4배 향상·Cpk 산출 신뢰도 99% 이상 확보, PPAP 대응 비용 분기당 4,200만 원 → 1,500만 원 이하 절감. ② 열처리 산포 예측·제어로 가공불량 0.8% → 0.3% 감축, 연삭휠 교체 주기 정상화로 연 1.2억 원 비용 절감. ③ 생산 스케줄링 최적화로 긴급 오더 응답시간 50% 단축·CNC 가동률 71% → 78% 이상 향상. ④ 외주 도금 품질 데이터 분석으로 클레임 월 1.2건 → 0.5건 이하·업체별 SLA 관리 체계 구축. ⑤ 숙련공 노하우(가열온도·침탄시간 등) 데이터 기반 표준화로 신규 인력 OJT 기간 6개월 → 3개월 단축. ⑥ 전기차 감속기 신사업 R&D에서 시뮬레이션·데이터 분석을 자체 수행해 외부 컨설팅 의존도 70% → 30% 감소. ⑦ 훈련 수료 후 부서별 AI 챔피언 5명(품질·생산기술·R&D·경영지원·구매) 양성, 사내 AI 활용 사례 전파.
```
