# 모바일 반응형 변경 로그

> 각 배치 완료 후 이 문서에 누적 기록한다.
> 모바일 실기기 또는 Chrome DevTools(320px, 375px)에서 이 문서를 따라가며 확인한다.
> 데스크톱(1024px 이상) 보호 확인도 함께 수행한다.

---

## Batch 0: 글로벌 CSS + 공통 UI 컴포넌트 (2026-02-19)

### 1. 전체 앱 — 한글 줄바꿈 및 미디어 방어

**확인 경로:** 모든 페이지

**기존:** 모바일에서 긴 한글 텍스트가 글자 중간에서 잘려 줄바꿈됨 (예: "교육과정" → "교육과" / "정"). 긴 URL이나 영문이 컨테이너를 뚫고 넘침.

**수정:** 한글은 항상 단어 단위로 줄바꿈됨 ("교육과정"이 통째로 다음 줄로 이동). 긴 URL/영문도 컨테이너 안에서 자동 줄바꿈. 이미지/비디오가 화면 너비를 넘지 않음.

**확인 포인트:**

- 아무 페이지에서 한글 텍스트가 글자 중간에서 끊기지 않는지 확인
- 긴 텍스트가 있는 곳에서 수평 스크롤바가 body에 나타나지 않는지 확인

### 2. 페이지네이션 — 테이블 하단 페이지 이동 버튼

**확인 경로:** 테이블이 있는 모든 페이지 하단 (예: 운영관리 > **사용자 관리**, 워크스페이스 > **프로젝트 관리**, **담당 프로젝트** 목록 등)

**기존:** 버튼(처음/이전/1 2 3/다음/마지막) 터치 영역이 작아 손가락으로 정확히 누르기 어려움. 좌우 패딩이 넓어 320px에서 버튼이 빽빽하게 밀림.

**수정:** 모든 버튼에 최소 높이 36px 적용으로 터치 편의성 확보. 모바일에서 좌우 패딩과 버튼 간격 축소로 공간 확보. 640px 이상에서는 기존과 동일.

**확인 포인트:**

- 페이지 번호 버튼을 손가락으로 편하게 누를 수 있는지 확인
- 버튼들이 겹치거나 잘리지 않는지 확인

### 3. 빈 상태 화면

**확인 경로:** 데이터가 없는 모든 페이지 (예: 프로젝트 0건일 때, 검색 결과 없을 때)

**기존:** 상하 패딩 48px, 아이콘 48x48px 고정. 모바일에서 빈 상태 메시지가 과하게 넓은 여백을 차지.

**수정:** 모바일에서 상하 패딩 32px, 아이콘 40x40px로 축소. 640px 이상에서는 기존 크기 유지.

**확인 포인트:**

- 빈 상태 화면이 모바일 화면에서 자연스러운 비율인지 확인

### 4. 로드맵 생성 로딩 모달

**확인 경로:** **테스트 로드맵** 메뉴 진입 → "로드맵 생성" 버튼 클릭 시 나타나는 로딩 오버레이. 또는 **담당 프로젝트** > 프로젝트 선택 > 로드맵 탭에서 생성 시.

**기존:** 모달 최대 너비 448px 고정 → 320px 폰에서 좌우 여백이 거의 없음. 스텝 라벨("요구사항 분석", "교육과정 설계", "로드맵 구성")이 줄바꿈 금지 → 좁은 화면에서 넘침. 팁 카드 패딩 16px 고정.

**수정:** 모달이 항상 화면 양쪽에 16px 여백 유지. 스텝 라벨이 모바일에서 줄바꿈 허용. 팁 카드 패딩을 모바일에서 12px로 축소. 640px 이상에서는 기존과 동일.

**확인 포인트:**

- 로딩 모달이 화면 좌우 끝에 닿지 않고 여백이 있는지 확인
- 3단계 스텝 라벨이 모두 읽을 수 있는지 확인
- 팁 카드 텍스트가 잘리지 않는지 확인

### 5. 자가진단 결과 항목별 점수

**확인 경로:** 워크스페이스 > **프로젝트 관리** > 프로젝트 선택 → "자가진단 결과" 섹션의 항목별 점수 영역. 또는 **로드맵 갤러리** > 로드맵 선택 → 자가진단 결과 섹션.

**기존:** 차원명(예: "데이터 활용 역량")이 112px 고정 너비 + 말줄임 → 7글자 이상이 "데이터 활용..."처럼 잘림. 점수(85/100)와 퍼센트(85%) 칸도 고정 너비.

**수정:** 모바일에서 차원명이 고정 너비 없이 전체 표시. 점수/퍼센트 칸 너비 축소. 매우 좁은 화면에서 줄바꿈 허용. 640px 이상에서는 기존 고정 너비 + 말줄임 유지.

**확인 포인트:**

- 모든 차원명이 잘리지 않고 완전히 보이는지 확인
- 점수와 퍼센트가 겹치지 않는지 확인
- 프로그레스 바가 정상적으로 표시되는지 확인

### 데스크톱 보호 확인

**확인 경로:** 위 5개 항목의 모든 페이지를 1024px 이상에서 확인

**확인 포인트:**

- 페이지네이션 버튼 크기/간격이 기존과 동일한지 확인
- 빈 상태 화면 패딩/아이콘 크기가 기존과 동일한지 확인
- 로딩 모달 너비가 기존 448px 그대로인지 확인
- 자가진단 차원명이 기존처럼 고정 너비 + 말줄임인지 확인
