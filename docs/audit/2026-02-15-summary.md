### 1. ✅ Next.js 16.1.x 보안 취약점 3건 (DoS + 무제한 메모리)
- **심각도:** ✅ 수정완료 (2026-02-15)
- **위치:** `package.json` → `next`
- **문제:** Image Optimizer remotePatterns DoS (high), RSC HTTP deserialization DoS (high), PPR Resume Endpoint 무제한 메모리 소비 (critical) — 외부 공격자가 서버를 다운시킬 수 있음
- **재현 방법:**
  1. `npm audit` 실행
  2. `next 15.6.0-canary.0 - 16.1.4` 범위에 3건의 취약점 표시됨
  3. 해당 엔드포인트에 악의적 요청 전송 시 서버 DoS 발생 가능
- **권장 수정:** `npm install next@16.1.6` 으로 패치 버전 업그레이드
- **공수:** S

### 2. ✅ fetchConsultantProgress — 인증 없이 adminSupabase로 개인정보 노출
- **심각도:** ✅ 수정완료 (2026-02-15)
- **위치:** `src/app/(dashboard)/ops/projects/actions/dashboard.ts:122`
- **문제:** `createAdminClient()`로 RLS를 완전히 우회하면서 `requireAuth()`조차 호출하지 않음. 모든 활성 컨설턴트의 이름, 이메일, 프로젝트 통계를 반환. Server Action은 미들웨어 인증을 건너뛰므로 인증된 사용자 누구나(USER_PENDING 포함) 호출 가능
- **재현 방법:**
  1. USER_PENDING 역할로 로그인
  2. 브라우저 콘솔에서 `fetchConsultantProgress()` Server Action 직접 호출
  3. 전체 컨설턴트 개인정보(이름, 이메일)와 업무 통계 노출
- **권장 수정:** `requireAuthWithRole(['OPS_ADMIN', 'SYSTEM_ADMIN'])` 추가
- **공수:** S

### 3. confirmFinalRoadmap — 역할+배정 검증 없이 누구나 로드맵 확정
- **심각도:** 🔴 치명
- **위치:** `src/app/(dashboard)/consultant/projects/[id]/roadmap/actions.ts:80`
- **문제:** `requireAuth()`만 사용하여 인증된 사용자 누구나(USER_PENDING 포함) 아무 로드맵이든 최종 확정 가능. 프로젝트 상태가 FINALIZED로 변경되며 기존 FINAL 버전이 ARCHIVED로 덮어씌워짐
- **재현 방법:**
  1. USER_PENDING 역할로 로그인
  2. `confirmFinalRoadmap('임의의-roadmapId')` Server Action 직접 호출
  3. 해당 로드맵이 FINAL 상태로 변경됨
- **권장 수정:** `requireAuthWithRole(['CONSULTANT_APPROVED'])` + `requireConsultantProjectAccess()` 추가
- **공수:** S

### 5. editRoadmapManually — 타 컨설턴트 로드맵 무단 변경 가능

- **공수:** M
